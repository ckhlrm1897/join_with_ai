# Join – Kanban Board

Join is a Kanban board application designed to organize and distribute tasks in a clear and visual way.  
This project was created as a **portfolio project** to demonstrate frontend skills, API integration, and workflow automation.

---

## 🚀 Features

- Create, edit, and delete tasks  
- Organize tasks using a Kanban board layout  
- Visual task distribution across different statuses  
- Persistent data storage via Firebase  
- Automated workflows powered by n8n  
- Responsive design for desktop and mobile devices  

---

## 🛠️ Tech Stack

- **Frontend:**  
  - HTML  
  - CSS  
  - JavaScript (Vanilla)

- **Backend / Services:**  
  - Firebase API (data storage & synchronization)  
  - n8n (workflow automation)

---

## 📦 Project Purpose

This project serves as a **portfolio project** and focuses on:

- Clean and maintainable JavaScript code  
- Working with external APIs (Firebase)  
- Automating processes using n8n  
- Structuring a real-world web application without frameworks
